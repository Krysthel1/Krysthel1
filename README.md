# Hola, soy Krysthel Espinoza

**Diseño UI/UX · Prototipado · Desarrollo frontend**

Me gusta convertir ideas en prototipos y llevarlos a interfaces web. Disfruto diseñar pantallas, construir componentes y organizar recorridos como el registro, la búsqueda de productos y el proceso de compra.

## Proyectos destacados

### ALTOQ · Marketplace para emprendedores
Trabajé en las pantallas de inicio, detalle de producto, favoritos, carrito y checkout. Con Angular, desarrollé componentes como las tarjetas de producto y ajusté la navegación entre las áreas de compra y venta. El proyecto usa FastAPI y MySQL.

### Edustay · Plataforma de alojamiento
Desarrollé la página de inicio en Angular y conecté el botón **Publicar alojamiento** con el formulario de registro.

### [inDrive IHM](https://github.com/Krysthel1/indrive_IHM) · Rediseño de una aplicación de viajes
Participé en el rediseño de la interfaz y en la implementación de vistas para los flujos de pasajeros y conductores. También trabajé con controladores en Spring Boot MVC y una base de datos MySQL.

## Tecnologías

- **Frontend** · Angular, AngularJS, TypeScript, JavaScript, HTML y CSS
- **Backend y datos** · Spring Boot, FastAPI y MySQL
