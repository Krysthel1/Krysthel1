# Krysthel Espinoza

**Diseño UI/UX · Prototipado · Desarrollo frontend**

Diseño interfaces web y las llevo del prototipo al código con Angular. Me enfoco en los pasos que una persona necesita completar, como guardar un producto, finalizar una compra o publicar un alojamiento.

## Proyectos destacados

### ALTOQ · Marketplace para emprendedores

Trabajé en la experiencia de compra, desde la página de inicio hasta el checkout. Desarrollé tarjetas de producto con la opción de guardar en favoritos y trabajé en las pantallas de detalle, carrito y confirmación del pedido. También ajusté la navegación para que una persona que registra su tienda pueda acceder al área de vendedor desde el menú.

**Tecnologías del proyecto** · Angular, TypeScript, FastAPI y MySQL

### Edustay · Plataforma de alojamiento

Desarrollé la página de inicio en Angular e integré el botón **Publicar alojamiento** con el formulario de registro. Así, quien llega a la página con la intención de publicar tiene un acceso directo al primer paso.

**Tecnologías del proyecto** · Angular, TypeScript, HTML y CSS

### inDrive IHM · Rediseño de una aplicación de viajes

Participé en el rediseño de la interfaz y en la implementación de vistas para pasajeros y conductores. También trabajé con controladores en Spring Boot MVC para conectar las vistas con la lógica de la aplicación.

**Tecnologías del proyecto** · HTML, CSS, Java, Spring Boot MVC y MySQL

[Ver mi rama de trabajo en GitHub](https://github.com/Krysthel1/indrive_IHM/tree/A-Krysthel)

- **Diseño y prototipado** · Organizo la información de cada pantalla y defino los pasos que conectan una vista con la siguiente.
